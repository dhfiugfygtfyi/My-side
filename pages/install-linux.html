Как установить языки программирования на Linux

Готовые команды для Ubuntu/Debian, Fedora и Arch Linux: Python, Node.js, C и C++, Java, C#, Go, Rust, PHP, Ruby, Kotlin и другие.

How to install programming languages on Linux

Ready-to-run commands for Ubuntu/Debian, Fedora and Arch Linux: Python, Node.js, C and C++, Java, C#, Go, Rust, PHP, Ruby, Kotlin and more.

apt dnf pacman ≈ 15 minutes

1. Подготовка системы

Команды зависят от дистрибутива. Сначала обновите список пакетов:

Bash 
# Ubuntu / Debian
sudo apt update

# Fedora
sudo dnf check-update

# Arch Linux
sudo pacman -Sy

Почти для всех языков пригодятся базовые инструменты сборки, git и curl:

Bash 
# Ubuntu / Debian
sudo apt install build-essential git curl

# Fedora
sudo dnf groupinstall "Development Tools"
sudo dnf install git curl

# Arch Linux
sudo pacman -S base-devel git curl
sudo нужен только для системных пакетов. Библиотеки языка ставьте в пользовательское окружение или через менеджеры версий: pyenv, nvm, rustup, sdkman.

2. Python

В большинстве дистрибутивов Python 3 уже есть. Если нет — установите вместе с pip и venv:

Bash 
# Ubuntu / Debian
sudo apt install python3 python3-pip python3-venv

# Fedora
sudo dnf install python3 python3-pip

# Arch Linux
sudo pacman -S python python-pip

Проверка: python3 --version. Для проектов создавайте окружение: python3 -m venv .venv.

3. JavaScript и Node.js

Версия Node.js из репозиториев дистрибутива часто отстаёт. Надёжнее поставить nvm — менеджер версий Node.js:

Bash 
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# перезапустите терминал
nvm install --lts
node --version
npm --version

Если нужна версия из репозитория дистрибутива:

Bash 
# Ubuntu / Debian
sudo apt install nodejs npm

# Fedora
sudo dnf install nodejs npm

# Arch Linux
sudo pacman -S nodejs npm

4. C и C++

Компиляторы GCC/G++ и make входят в набор инструментов разработчика:

Bash 
# Ubuntu / Debian
sudo apt install build-essential

# Fedora
sudo dnf install gcc gcc-c++ make

# Arch Linux
sudo pacman -S base-devel

Проверка: gcc --version и g++ --version. Вместо GCC можно поставить Clang: sudo apt install clang, sudo dnf install clang или sudo pacman -S clang.

5. Java

Установите JDK — он включает и компилятор javac, и среду выполнения:

Bash 
# Ubuntu / Debian (JDK 21)
sudo apt install openjdk-21-jdk

# Fedora
sudo dnf install java-21-openjdk-devel

# Arch Linux
sudo pacman -S jdk-openjdk

Проверка: java -version и javac -version. Для нескольких версий JDK удобен sdkman.

6. C# и .NET

В Ubuntu 24.04+ пакет .NET 8 есть в официальном репозитории:

Bash 
sudo apt install dotnet-sdk-8.0
dotnet --version

Если пакет не найден, подключите репозиторий Microsoft по инструкции на learn.microsoft.com/dotnet или используйте официальный скрипт:

Bash 
curl -sSL https://dot.net/v1/dotnet-install.sh | bash /dev/stdin --channel 8.0
echo 'export PATH=$PATH:$HOME/.dotnet' >> ~/.profile
source ~/.profile
dotnet --version

7. Go

Bash 
# Ubuntu / Debian
sudo apt install golang-go

# Fedora
sudo dnf install golang

# Arch Linux
sudo pacman -S go

Версия из репозитория может отставать. Официальный способ — скачать актуальный архив с go.dev/dl:

Bash 
curl -LO https://go.dev/dl/go1.23.4.linux-amd64.tar.gz
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.23.4.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.profile
source ~/.profile
go version

8. Rust

Официальный установщик rustup ставит компилятор и cargo в домашнюю папку:

Bash 
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustc --version
cargo --version

Или версия из репозитория дистрибутива:

Bash 
sudo apt install rustc cargo
sudo dnf install rust cargo
sudo pacman -S rust

9. PHP, Ruby, Kotlin и другие

PHP:

Bash 
sudo apt install php php-cli php-mbstring
sudo dnf install php-cli php-mbstring
sudo pacman -S php

Ruby:

Bash 
sudo apt install ruby-full
sudo dnf install ruby
sudo pacman -S ruby

Kotlin через snap или sdkman:

Bash 
sudo snap install kotlin --classic

# или sdkman
curl -s "https://get.sdkman.io" | bash
sdk install kotlin

Lua и Perl обычно есть в репозиториях: sudo apt install lua5.4 perl, sudo dnf install lua perl, sudo pacman -S lua perl.

10. Проверка всех версий

Одна команда на каждый язык — удобно проверить, что всё установилось:

Bash 
python3 --version
node --version
gcc --version | head -n1
g++ --version | head -n1
java -version
dotnet --version
go version
rustc --version
php --version | head -n1
ruby --version
kotlin -version
Если сразу после установки команда не найдена, откройте новый терминал — оболочка должна заново прочитать PATH.

11. Частые проблемы

  • E: Unable to locate package. Выполните sudo apt update и проверьте имя пакета для вашей версии дистрибутива.
  • command not found после установки. Откройте новый терминал или проверьте PATH. Для скриптов, добавленных в ~/.profile, нужен повторный вход.
  • Старая версия из репозитория. Используйте официальный установщик или менеджер версий: nvm, pyenv, rustup, sdkman.
  • Permission denied при установке библиотек. Не используйте sudo для pip, npm и cargo — ставьте пакеты в пользовательское окружение.
  • Конфликт версий. Держите версии изолированно: venv для Python, nvm для Node.js, sdkman для Java и Kotlin, rustup для Rust.
  • Мало места на диске. Очистите кэш пакетов: sudo apt clean, sudo dnf clean all или sudo pacman -Sc.

1. Prepare the system

Commands depend on the distribution. Refresh the package index first:

Bash 
# Ubuntu / Debian
sudo apt update

# Fedora
sudo dnf check-update

# Arch Linux
sudo pacman -Sy

Most languages need basic build tools, git and curl:

Bash 
# Ubuntu / Debian
sudo apt install build-essential git curl

# Fedora
sudo dnf groupinstall "Development Tools"
sudo dnf install git curl

# Arch Linux
sudo pacman -S base-devel git curl
Use sudo only for system packages. Install language libraries in a user environment or with version managers: pyenv, nvm, rustup, sdkman.

2. Python

Most distributions already include Python 3. If yours does not, install it together with pip and venv:

Bash 
# Ubuntu / Debian
sudo apt install python3 python3-pip python3-venv

# Fedora
sudo dnf install python3 python3-pip

# Arch Linux
sudo pacman -S python python-pip

Check it with python3 --version. For projects, create an environment: python3 -m venv .venv.

3. JavaScript and Node.js

The Node.js version in distribution repositories is often outdated. nvm, the Node.js version manager, is more reliable:

Bash 
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# restart the terminal
nvm install --lts
node --version
npm --version

If you prefer the distribution package:

Bash 
# Ubuntu / Debian
sudo apt install nodejs npm

# Fedora
sudo dnf install nodejs npm

# Arch Linux
sudo pacman -S nodejs npm

4. C and C++

GCC/G++ compilers and make are part of the development tools group:

Bash 
# Ubuntu / Debian
sudo apt install build-essential

# Fedora
sudo dnf install gcc gcc-c++ make

# Arch Linux
sudo pacman -S base-devel

Check with gcc --version and g++ --version. You can install Clang instead: sudo apt install clang, sudo dnf install clang or sudo pacman -S clang.

5. Java

Install a JDK — it includes both the javac compiler and the runtime:

Bash 
# Ubuntu / Debian (JDK 21)
sudo apt install openjdk-21-jdk

# Fedora
sudo dnf install java-21-openjdk-devel

# Arch Linux
sudo pacman -S jdk-openjdk

Check with java -version and javac -version. sdkman is handy when you need several JDK versions.

6. C# and .NET

Ubuntu 24.04+ ships .NET 8 in the official repository:

Bash 
sudo apt install dotnet-sdk-8.0
dotnet --version

If the package is not found, add the Microsoft repository as described at learn.microsoft.com/dotnet, or use the official script:

Bash 
curl -sSL https://dot.net/v1/dotnet-install.sh | bash /dev/stdin --channel 8.0
echo 'export PATH=$PATH:$HOME/.dotnet' >> ~/.profile
source ~/.profile
dotnet --version

7. Go

Bash 
# Ubuntu / Debian
sudo apt install golang-go

# Fedora
sudo dnf install golang

# Arch Linux
sudo pacman -S go

The repository version may lag behind. The official way is to download the current archive from go.dev/dl:

Bash 
curl -LO https://go.dev/dl/go1.23.4.linux-amd64.tar.gz
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.23.4.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.profile
source ~/.profile
go version

8. Rust

The official rustup installer puts the compiler and cargo in your home directory:

Bash 
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustc --version
cargo --version

Or the distribution package:

Bash 
sudo apt install rustc cargo
sudo dnf install rust cargo
sudo pacman -S rust

9. PHP, Ruby, Kotlin and more

PHP:

Bash 
sudo apt install php php-cli php-mbstring
sudo dnf install php-cli php-mbstring
sudo pacman -S php

Ruby:

Bash 
sudo apt install ruby-full
sudo dnf install ruby
sudo pacman -S ruby

Kotlin via snap or sdkman:

Bash 
sudo snap install kotlin --classic

# or sdkman
curl -s "https://get.sdkman.io" | bash
sdk install kotlin

Lua and Perl are usually available in the repositories: sudo apt install lua5.4 perl, sudo dnf install lua perl, sudo pacman -S lua perl.

10. Check all versions

One command per language — a quick way to confirm everything is installed:

Bash 
python3 --version
node --version
gcc --version | head -n1
g++ --version | head -n1
java -version
dotnet --version
go version
rustc --version
php --version | head -n1
ruby --version
kotlin -version
If a command is not found right after installation, open a new terminal so the shell reloads PATH.

11. Common problems

  • E: Unable to locate package. Run sudo apt update and check the package name for your distribution version.
  • command not found after installation. Open a new terminal or check PATH. Scripts added to ~/.profile require a new login session.
  • An old version from the repository. Use the official installer or a version manager: nvm, pyenv, rustup, sdkman.
  • Permission denied when installing libraries. Do not use sudo with pip, npm or cargo — install packages in a user environment.
  • Version conflicts. Keep versions isolated: venv for Python, nvm for Node.js, sdkman for Java and Kotlin, rustup for Rust.
  • Running out of disk space. Clean the package cache: sudo apt clean, sudo dnf clean all or sudo pacman -Sc.
