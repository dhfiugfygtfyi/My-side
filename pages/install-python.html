Как установить Python

Пошаговая инструкция для Windows, macOS и Linux: где скачать, как включить PATH, проверить версию и настроить виртуальное окружение.

How to install Python

A step-by-step guide for Windows, macOS and Linux: where to download it, how to enable PATH, check the version and set up a virtual environment.

Windows macOS Linux ≈ 10 minutes

1. Проверьте, установлен ли Python

Откройте терминал: в Windows — PowerShell, в macOS и Linux — Terminal. Выполните команды:

Терминал 
python3 --version
python --version
py --version

Если в ответ появилось что-то вроде Python 3.12.4, Python уже установлен. Если команда не найдена — переходите к установке. В Windows основной лаунчер обычно называется py.

2. Установка на Windows

  1. Скачайте установщик

    Откройте python.org/downloads и нажмите кнопку загрузки последней версии Python 3.

  2. Включите PATH

    На первом экране установщика обязательно поставьте галочку Add python.exe to PATH. Без неё команда python не будет работать в терминале.

  3. Установите

    Нажмите Install Now и дождитесь завершения. Права администратора нужны только при установке «для всех пользователей».

  4. Проверьте

    Закройте PowerShell и откройте заново, затем выполните py --version.

Можно поставить Python через winget: winget install --id Python.Python.3.12 -e. Подставьте актуальный номер версии. Не скачивайте установщики со сторонних сайтов.

3. Установка на macOS

  1. Проверьте версию

    В macOS часто уже есть Python 3. Выполните python3 --version. Если версия есть, отдельная установка не нужна.

  2. Установите через python.org или Homebrew

    Универсальный установщик лежит на python.org/downloads/macos. Если установлен Homebrew, проще так:

    Bash 
    brew install python

  3. Проверьте pip

    Выполните python3 --version и pip3 --version. Команда python на macOS может отсутствовать или указывать на старую версию — используйте python3.

4. Установка на Linux

В большинстве дистрибутивов Python 3 уже установлен. Если его нет, используйте пакетный менеджер:

Bash 
# Ubuntu / Debian
sudo apt update
sudo apt install python3 python3-pip python3-venv

# Fedora
sudo dnf install python3 python3-pip

# Arch Linux
sudo pacman -S python python-pip
Не удаляйте системный Python — от него зависят служебные скрипты дистрибутива. Для своих проектов создавайте виртуальное окружение.

5. Проверка установки

Убедитесь, что доступны сам Python, pip и модуль venv:

Терминал 
python3 --version
pip3 --version
python3 -m venv --help

Если pip не найден, включите его вручную: python3 -m ensurepip --upgrade в Linux и macOS или py -m ensurepip --upgrade в Windows.

6. Первая программа и виртуальное окружение

Создайте папку проекта и окружение .venv — так зависимости проекта не смешаются с системными:

Терминал 
mkdir myproject
cd myproject
python3 -m venv .venv

Активируйте окружение:

Терминал 
# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

Создайте файл hello.py:

Python 
print("Привет, Python!")

Запустите его командой python3 hello.py (в Windows — py hello.py). В активированном окружении пакеты ставятся через pip install requests, а список зависимостей сохраняется командой pip freeze > requirements.txt.

7. Частые проблемы

  • Команда python не найдена, а python3 работает. Используйте python3 или настройте псевдоним в shell.
  • Windows: забыта галочка PATH. Переустановите Python с галочкой Add python.exe to PATH или добавьте папку установки в переменную PATH вручную.
  • Ошибка externally-managed-environment. В Ubuntu 23.04+ и Debian 12 нельзя ставить пакеты в системный Python. Создайте venv или используйте pipx.
  • pip не найден. Выполните python3 -m ensurepip --upgrade.
  • Несколько версий Python. В Windows py -0 показывает список, а py -3.12 запускает нужную версию.
  • Permission denied при установке пакета. Не используйте sudo pip — работайте в виртуальном окружении.

8. Что дальше

Когда Python установлен, переходите к практике: синтаксис, переменные, условия и первые проекты.

1. Check whether Python is already installed

Open a terminal: PowerShell on Windows, Terminal on macOS and Linux. Run:

Terminal 
python3 --version
python --version
py --version

If you see something like Python 3.12.4, Python is already installed. If the command is not found, continue with the installation. On Windows the launcher is usually called py.

2. Install on Windows

  1. Download the installer

    Open python.org/downloads and click the download button for the latest Python 3 release.

  2. Enable PATH

    On the first installer screen, tick Add python.exe to PATH. Without it the python command will not work in the terminal.

  3. Install

    Click Install Now and wait for it to finish. Administrator rights are only needed for an all-users installation.

  4. Verify

    Close PowerShell, open it again and run py --version.

You can also install Python with winget: winget install --id Python.Python.3.12 -e. Use the current version number. Avoid installers from third-party sites.

3. Install on macOS

  1. Check the version

    macOS often ships with Python 3. Run python3 --version. If a version is reported, no separate installation is needed.

  2. Install from python.org or Homebrew

    The universal installer is available at python.org/downloads/macos. If Homebrew is installed, this is simpler:

    Bash 
    brew install python

  3. Check pip

    Run python3 --version and pip3 --version. The python command may be missing or point to an old version on macOS — use python3.

4. Install on Linux

Most distributions already include Python 3. If yours does not, use the package manager:

Bash 
# Ubuntu / Debian
sudo apt update
sudo apt install python3 python3-pip python3-venv

# Fedora
sudo dnf install python3 python3-pip

# Arch Linux
sudo pacman -S python python-pip
Do not remove the system Python — distribution tools depend on it. Use a virtual environment for your own projects.

5. Verify the installation

Make sure Python, pip and the venv module are available:

Terminal 
python3 --version
pip3 --version
python3 -m venv --help

If pip is missing, enable it manually: python3 -m ensurepip --upgrade on Linux and macOS, or py -m ensurepip --upgrade on Windows.

6. First program and a virtual environment

Create a project folder and a .venv environment so project dependencies stay separate from system packages:

Terminal 
mkdir myproject
cd myproject
python3 -m venv .venv

Activate the environment:

Terminal 
# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

Create a file named hello.py:

Python 
print("Hello, Python!")

Run it with python3 hello.py (py hello.py on Windows). Inside an active environment install packages with pip install requests and save the dependency list with pip freeze > requirements.txt.

7. Common problems

  • The python command is missing, but python3 works. Use python3 or create a shell alias.
  • Windows: the PATH checkbox was missed. Reinstall Python with Add python.exe to PATH ticked, or add the install folder to PATH manually.
  • externally-managed-environment error. Ubuntu 23.04+ and Debian 12 block packages in the system Python. Create a venv or use pipx.
  • pip is missing. Run python3 -m ensurepip --upgrade.
  • Multiple Python versions. On Windows, py -0 lists them and py -3.12 runs a specific version.
  • Permission denied while installing a package. Do not use sudo pip — work inside a virtual environment.

8. What next

Once Python is installed, move on to practice: syntax, variables, conditions and your first projects.
