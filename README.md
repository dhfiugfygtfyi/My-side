# My-side — регистрация и вход

Статичный сайт с регистрацией, входом и личным кабинетом.
Бэкенда нет: пользователи хранятся в `localStorage` браузера.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная: шапка с приветствием и кнопкой «Выйти», карточка аккаунта |
| `login.html` | Страница входа: логин **или** email + пароль |
| `register.html` | Регистрация: логин, email, пароль, Cloudflare Turnstile |
| `style.css` | Тёмная тема, общая для всех страниц |
| `app.js` | Аккаунты, хеширование пароля, сессия, шапка, формы |
| `favicon*`, `app.ico` | Иконки — не изменялись |

## Где лежат пользователи

Регистрация пишет массив в `localStorage` под ключом **`registeredUsers`**:

```js
JSON.parse(localStorage.getItem("registeredUsers"));
// [
//   {
//     login: "player_one",
//     email: "you@example.com",
//     passwordHash: "…",
//     passwordAlgo: "sha256",
//     createdAt: 1793950000000
//   }
// ]
```

Вход ищет пользователя именно в этом массиве — совпадение по `login`
**или** `email` (регистр не важен), затем сверяет пароль с `passwordHash`.

Кто сейчас вошёл, хранится отдельно, под ключом
**`gitcom_currentUser`** — обычная строка с логином:

```js
localStorage.getItem("gitcom_currentUser"); // "player_one"
```

## Как работает пароль

- Пароль **не хранится в открытом виде**: сохраняется SHA-256-хеш
  (с префиксом `myside:`), в поле `passwordHash`.
- Если `crypto.subtle` недоступен (например, при открытии через `file://`),
  используется резервный хеш FNV-1a, а в записи появляется
  `passwordAlgo: "fnv1a"`.
- Аккаунты, созданные старой версией сайта, не содержат пароля. При первом
  входе введённый пароль привязывается к такому аккаунту и сохраняется как хеш.
  Дальше вход работает как обычно.

## Проверка

1. Откройте сайт по `https://` (GitHub Pages) или через локальный сервер:

   ```bash
   python -m http.server 8000
   ```

2. Зарегистрируйтесь на `register.html` — после успеха произойдёт
   автоматический вход и редирект на главную.
3. В шапке появится «Привет, {логин}» и кнопка «Выйти».
4. Выйдите и войдите на `login.html` — можно вводить логин или email.
5. Неверный пароль или неизвестный пользователь → красное сообщение
   на странице (без `alert`).

Очистить все данные сайта в браузере: откройте `index.html?reset=1`.

## Важно

- Капча Turnstile работает только по `http://` или `https://`.
  Site Key привязан к домену `dhfiugfygtfyi.github.io`; на `localhost`
  капча может не пройти — для локальной проверки формы регистрации
  используйте GitHub Pages.
- Это демо без сервера: «аккаунт» живёт только в одном браузере.
  Для настоящей авторизации нужен бэкенд и проверка токена Turnstile
  через `siteverify` с Secret Key.
