# Регистрация с капчей Cloudflare Turnstile

Статичный сайт с формой регистрации и капчей Cloudflare Turnstile.
Бэкенда нет: после успешной проверки логин и email сохраняются в `localStorage`
браузера. Пароль нигде не сохраняется.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Страница регистрации: логин, email, пароль, виджет Turnstile, кнопка |
| `style.css` | Стили: карточка по центру, скруглённые углы, тень, синяя кнопка |
| `app.js` | Site Key, валидация полей, проверка капчи, сохранение в `localStorage` |

## 1. Получить Site Key

1. Откройте [dash.cloudflare.com](https://dash.cloudflare.com/) и войдите в аккаунт.
2. В меню слева выберите **Turnstile**.
3. Нажмите **Add site** (Добавить сайт).
4. Укажите:
   - **Site name** — любое название, например `My GitHub Pages`;
   - **Domain** — домен в формате `username.github.io`
     (например, `dhfiugfygtfyi.github.io`), без `https://` и без пути к репозиторию;
   - **Widget Mode** — **Managed**.
5. Сохраните. Cloudflare покажет **Site Key** и **Secret Key**.
   Для статичного сайта нужен только **Site Key** (Secret Key не используется,
   потому что серверной проверки нет).

## 2. Вставить Site Key

Откройте `app.js` и замените значение константы в самой первой строке:

```js
// вставь свой Site Key из dash.cloudflare.com
const SITE_KEY = "0x4AAAAAAA...";
```

`app.js` сам подставит ключ в `data-sitekey` виджета в `index.html`,
поэтому больше ничего менять не нужно.

## 3. Включить GitHub Pages

1. Загрузите файлы (`index.html`, `style.css`, `app.js`, `README.md`) в репозиторий
   на GitHub (ветка `main`).
2. Откройте репозиторий → **Settings** → **Pages**.
3. В блоке **Build and deployment**:
   - **Source** — **Deploy from a branch**;
   - **Branch** — `main`, папка — `/ (root)`.
4. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://username.github.io/repository/`.

## 4. Проверка

- Откройте страницу по адресу GitHub Pages.
- Заполните поля, пройдите капчу и нажмите **Зарегистрироваться**.
- Должно появиться сообщение **«Регистрация успешна!»**.
- Проверить сохранённые данные можно в консоли браузера:

```js
JSON.parse(localStorage.getItem("registeredUsers"));
```

## Таблица пользователей

Под формой выводится таблица **«Зарегистрированные»** с колонками **Логин** и **Email**.
Она обновляется сразу после успешной регистрации, пароль в неё не попадает.

Важно: сайт статичный, поэтому список берётся из `localStorage` **текущего браузера**.
Каждый посетитель видит только тех, кто регистрировался у него на устройстве.
Общая таблица для всех посетителей требует бэкенда (базы данных).

## Важно

- Капча работает только по `http://` или `https://`. При открытии файла
  напрямую (`file://`) Turnstile не загрузится — используйте GitHub Pages
  или локальный сервер, например:
  ```bash
  python -m http.server 8000
  ```
- Site Key привязан к домену. Если открыть сайт на другом домене,
  капча покажет ошибку — добавьте этот домен в настройках Turnstile.
- Это демо без бэкенда: данные лежат только в браузере пользователя,
  поэтому «регистрация» не является настоящей учётной записью.
  Для реальной регистрации нужен сервер, который проверит токен Turnstile
  через `siteverify` с Secret Key.
- Пароль в `localStorage` не сохраняется — только `{ login, email }`.
