# My-side — каталог гайдов по языкам программирования

Статичный сайт-каталог: поиск и фильтры по языкам, пошаговые гайды, тёмная и
светлая темы. Регистрация и вход работают без бэкенда — данные хранятся в
`localStorage` браузера.

## Структура

```
index.html          каталог языков (поиск, фильтры, сортировка)
login.html          вход (логин или email + пароль + Turnstile)
register.html       регистрация (логин, email, пароль + Turnstile)
pages/
  guide.html        страница гайда: pages/guide.html?lang=python
css/
  style.css         тёмная/светлая темы, каталог, гайды, авторизация
js/
  theme.js          тема оформления и мобильное меню
  app.js            регистрация, вход, сессия, шапка (не менялось по логике)
  catalog.js        поиск, фильтры, сортировка, карточки языков
  guide.js          рендер гайда по ?lang=..., подсветка и копирование кода
data/
  languages.json    список языков и их характеристики
  guides.json       содержимое полных гайдов
favicon* / app.ico  иконки (не изменялись)
```

## Каталог

Главная страница читает `data/languages.json` и строит карточки сама.
Поддерживается:

- поиск по названию, описанию, назначению и сложности;
- фильтр по назначению: веб, игры, мобильные приложения, анализ данных;
- сортировка по популярности, алфавиту и году появления;
- состояние фильтров сохраняется в адресной строке (`?q=...&purpose=...&sort=...`).

### Как добавить новый язык

1. Допишите объект в `data/languages.json`:

   ```json
   {
     "slug": "zig",
     "name": "Zig",
     "icon": "⚡",
     "color": "#F7A41D",
     "year": 2016,
     "popularity": 40,
     "difficulty": "Высокий",
     "paradigm": "Императивный",
     "tagline": "Короткая строка для карточки",
     "description": "Полное описание для страницы гайда.",
     "purposes": ["web", "data"],
     "full": false
   }
   ```

2. Готово: карточка появится в каталоге автоматически. Если `full` равно
   `false` или для языка нет записи в `data/guides.json`, откроется страница
   с заглушкой «Гайд в разработке».

### Как добавить полный гайд

Добавьте в `data/guides.json` запись с ключом, равным `slug` языка:

```json
{
  "zig": {
    "sections": [
      {
        "id": "what",
        "title": "1. Что это за язык и для чего он",
        "blocks": [
          { "type": "p", "text": "Абзац текста." },
          { "type": "list", "items": ["Пункт 1", "Пункт 2"] }
        ]
      }
    ]
  }
}
```

Поддерживаемые типы блоков:

| Тип | Назначение |
| --- | --- |
| `p` | абзац |
| `list` | маркированный список |
| `steps` | нумерованные шаги с заголовками |
| `code` | блок кода с подсветкой (`language`) |
| `lines` | разбор строки кода с пояснением |
| `note` | врезка-подсказка |
| `links` | карточки-ссылки на другие гайды |

Полные гайды сейчас есть для Python, JavaScript, C++, Java и C#.

## Темы

Переключатель в шапке сохраняет выбор в `localStorage["myside_theme"]`
(`dark` по умолчанию или `light`). Тема применяется до отрисовки страницы,
поэтому нет вспышки светлого фона. Для подсветки кода подключены две темы
highlight.js; нужная включается автоматически.

## Авторизация

Логика входа и регистрации осталась прежней, изменились только пути к файлам
(`css/style.css`, `js/app.js`) и добавлен базовый путь для страниц в `pages/`.

- Пользователи: `localStorage["registeredUsers"]` — массив
  `{ login, email, passwordHash, passwordAlgo, createdAt }`.
- Текущий пользователь: `localStorage["gitcom_currentUser"]` — строка с логином.
- После входа и регистрации выполняется переход на `index.html` — главную
  страницу каталога.
- В шапке отображается «Привет, {логин}» и кнопка «Выйти».

Пароль хранится не в открытом виде, а как SHA-256-хеш (с префиксом `myside:`).
Старые аккаунты без пароля привязывают введённый пароль при первом входе.

Очистить все данные сайта в браузере: откройте `index.html?reset=1`.

## Локальный запуск

Каталог загружает JSON через `fetch`, поэтому открывать `index.html` напрямую
через `file://` нельзя — нужен локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/.

На GitHub Pages всё работает без дополнительных настроек.
